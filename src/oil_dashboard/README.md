# Brent Oil Price Analytics Dashboard

This full-stack interactive dashboard allows stakeholders to visualize and filter historical Brent Crude oil price fluctuations alongside structural econometric events (conflicts, policy changes, and economic sanctions).

## System Requirements
- Python 3.9+
- Node.js 18+
